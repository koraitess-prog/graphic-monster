# Material choice studies

Approved direction: five distinct material vocabularies and four contrasting pairs.
Slot: wordless draggable answer objects on #202426. No captions in the app.
Technique: existing Anidoodle kit seeded drawing, tornContour / paperCutout anatomy,
and creature engravingTile print plates. Silent, static source art; interaction remains
with the existing pointer / keyboard system. No creature DNA or saved records changed.

Typography uses interlocked open-counter letter fragments; grid is woven strips;
color is overlapping ink masses; shape is an open hooked contour; texture is a dry
rubbing. Following pairs compare aligned / tangled ribbons, a single focal disk /
punched apertures, quiet stock / layered print, and a fold / a curled gesture.

Mobile: one horizontally scrollable row of five 120px targets, then two large objects.
Review: /qa/question-materials.html. Labels there are review-only.
